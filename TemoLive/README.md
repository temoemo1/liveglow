# TemoLive - تطبيق بث مباشر متكامل

## 📱 نظرة عامة
تطبيق TemoLive هو تطبيق بث مباشر متكامل مشابه لتطبيق Poppo، يتضمن نظام هدايا احترافي متحرك مع مؤثرات صوتية، ولوحة تحكم شاملة لإدارة جميع جوانب التطبيق.

## 🎯 المميزات الرئيسية

### تطبيق المستخدم (TemoLive App)
- ✅ تسجيل الدخول/إنشاء حساب (بريد إلكتروني، هاتف، وسائل تواصل اجتماعي)
- ✅ البث المباشر مع دعم الفيديو والصوت
- ✅ الدردشة الحية خلال البث
- ✅ نظام الهدايا المتحركة الاحترافي (8 أنواع من الهدايا)
- ✅ معارك PK Battle بين المذيعين
- ✅ الملف الشخصي مع المحفظة الإلكترونية
- ✅ نظام المتابعين والمستويات
- ✅ واجهة مستخدم عصرية وسريعة الاستجابة

### لوحة التحكم (Admin Panel)
- ✅ لوحة إحصائيات شاملة مع رسوم بيانية
- ✅ إدارة المستخدمين (عرض، تعديل، حظر)
- ✅ مراقبة وإدارة البثوث المباشرة
- ✅ إدارة نظام الهدايا (إضافة، تعديل، حذف)
- ✅ النظام المالي والتقارير
- ✅ إشراف المحتوى ومراجعته
- ✅ إعدادات التطبيق الشاملة

## 📁 هيكل المشروع

```
TemoLive/
├── app/                    # تطبيق المستخدم
│   ├── index.html         # الصفحة الرئيسية للتطبيق
│   ├── styles.css         # أنماط التطبيق
│   └── app.js             # منطق التطبيق
│
├── admin/                  # لوحة التحكم
│   ├── index.html         # صفحة لوحة التحكم
│   ├── admin-styles.css   # أنماط لوحة التحكم
│   └── admin.js           # منطق لوحة التحكم
│
└── assets/                 # الملفات الثابتة
    ├── images/            # الصور (شعار، صور شخصية، إلخ)
    ├── audio/             # ملفات الصوت للهدايا
    └── animations/        # ملفات الرسوم المتحركة
```

## 🚀 كيفية التشغيل

### تشغيل التطبيق
1. افتح ملف `app/index.html` في متصفحك
2. يمكنك التسجيل أو تسجيل الدخول
3. استكشف البثوث المباشرة وأرسل الهدايا

### تشغيل لوحة التحكم
1. افتح ملف `admin/index.html` في متصفحك
2. استخدم بيانات المدير للدخول
3. تحكم في جميع جوانب التطبيق

## 🛠️ التقنيات المستخدمة

### الواجهة الأمامية (Frontend)
- HTML5 & CSS3
- JavaScript (Vanilla ES6+)
- Chart.js للرسوم البيانية
- Font Awesome للأيقونات
- تصميم متجاوب (Responsive Design)

### ميزات مقترحة للتطوير المستقبلي
- **Backend**: Node.js/Express أو Python/Django
- **قاعدة البيانات**: MongoDB أو PostgreSQL
- **البث المباشر**: WebRTC, Socket.io
- **تخزين الفيديو**: AWS S3, CloudFront CDN
- **المصادقة**: JWT, OAuth 2.0

## 📝 ملاحظات مهمة

1. **الصور والملفات**: يجب إضافة الصور الفعلية في مجلد `assets/images/`:
   - `logo.png` - شعار التطبيق
   - `avatar.png` - صورة المستخدم الافتراضية
   - صور أخرى للبثوث والمستخدمين

2. **ملفات الصوت**: يمكن إضافة ملفات الصوت للهدايا في `assets/audio/`:
   - `pop.mp3`, `crunch.mp3`, `pour.mp3`, إلخ

3. **الخادم**: هذا النموذج يعمل على جانب العميل فقط. للإنتاج، تحتاج إلى:
   - خادم backend
   - قاعدة بيانات
   - خادم بث فيديو (Streaming Server)
   - نظام تخزين سحابي
