# LiveGlow

A live streaming Android application.

## Description

LiveGlow is a modern Android application for live streaming experiences.

## Requirements

- Android SDK 24 or higher
- Java 8 or higher
- Gradle 8.0

## Building the Project

To build the project, use the Gradle wrapper:

```bash
./gradlew build
```

## Running the App

To install and run the app on a connected device or emulator:

```bash
./gradlew installDebug
```

## Project Structure

- `app/` - Main application module
  - `src/main/java/` - Java source files
  - `src/main/res/` - Android resources (layouts, strings, etc.)
  - `AndroidManifest.xml` - Application manifest
